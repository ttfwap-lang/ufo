# Workspace Rules: Environment Intent & Script Separation

## 1. Novelty vs. Production Separation
- **Bash & macOS Scripts (`.sh`)**:
  - Reserved strictly for **fictional, visual novelty, and cinematic terminal art**.
  - All exploits, root escalation telemetry, and hacking narratives in these scripts are simulated for visual entertainment only.
  - Development in this workspace for novelty and cinematic effects targets macOS and POSIX-compatible Bash environments.
- **Windows Scripts (`.ps1`, `.bat`, `.cmd`, `.lnk`)**:
  - Production scripts for actual workstation operations (e.g., UFO / BankFidelity launcher proxies).
  - **Zero-Modification Invariant**: Windows scripts must **NEVER** be modified, replaced, or deleted for novelty/cinematic purposes. Always preserve original Windows scripts in their pristine, authentic operational state.
